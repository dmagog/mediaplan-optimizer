# Проверка расширений мира, 2026-09-10

140 тестов пройдены; `ruff check .` и обе границы `lint-imports` соблюдены.
Тесты включают таргетинг через API, повтор из manifest, полный эпизод 504 часа,
no-leakage, нулевые/большие caps, фрод, SMS и конкурентов.

Команда: `.venv/bin/python -m scripts.validate_world_extensions --seeds 30`.
Бриф: 1,2 млн ₽, 21 день, максимум конверсий, все каналы, без таргетинга.
Catalog seed 0, world seeds 1–30, noise seed 10000 + world seed.
Матрица: 10 % меньшего пула для каждой пары; фоновая доля ботов programmatic 3 %.
Adaptive использует существующие настройки; под результаты не подбирался.
Всего 240 эпизодов: 4 сценария × 30 пар × 2 стратегии.

| Сценарий | Стратегия | Конечное отклонение KPI, среднее ± SD | WAPE накопленного KPI после шока | MAE накопленного KPI после шока, конверсий |
|---|---|---:|---:|---:|
| Спокойный рынок | static | 23,25 ± 23,43 % | 23,61 % | 418,46 |
| Спокойный рынок | adaptive | 16,53 ± 13,42 % | 19,99 % | 354,37 |
| Фрод programmatic | static | 23,27 ± 23,25 % | 23,61 % | 418,56 |
| Фрод programmatic | adaptive | 16,55 ± 13,40 % | 20,00 % | 354,42 |
| Недельная квота SMS | static | 23,25 ± 23,43 % | 23,67 % | 383,91 |
| Недельная квота SMS | adaptive | 16,64 ± 13,45 % | 20,48 % | 332,18 |
| Конкурент | static | 21,92 ± 17,96 % | 22,26 % | 394,55 |
| Конкурент | adaptive | 16,80 ± 12,62 % | 19,14 % | 339,22 |

Нарушений инвариантов и общего бюджета: **0 во всех 240 эпизодах**.
SD — стандартное отклонение по мирам, не доверительный интервал среднего.
Числа пересчитаны 10.09 на объединённой сборке. Предыдущая версия этого отчёта
осталась от 5 сентября — до слияния с миром коллег (фрод 3 % в programmatic,
пересечения аудиторий в ретро-пробах), и по ней adaptive показывал отклонение
11,6 % вместо 16,5 %. Разница именно от слияния: на прежнем коде и тех же
30 мирах сегодня выходит то же 16,5 %.
Post-shock метрики считаются по накопленной траектории с часа начала шока
до конца, а не по приращениям KPI только после события. В stable для
сопоставимости использовано окно с часа 240; SMS — с часа 168.

Ограничения интерпретации: это регрессия существующего оптимизатора на
расширенном мире, а не доказательство эффективности специального антифрода.
В этом медиаплане static не исчерпывает половинную квоту SMS, поэтому её шок
не меняет итог static. Воздействие фрода на итог всех каналов тоже небольшое;
рост CTR и падение конверсий самого programmatic проверяются отдельно на
фиксированном бюджете в `test_world_extensions.py`. По умолчанию оптимизатор
не использует `fraud_share` как отдельный сигнал принятия решений.
Дедуплицированный reach пока не входит в прогноз планировщика.
